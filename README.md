### About Me

I build functional and interactive web applications end-to-end — from React/Next.js frontends to backend systems handling real payments, background jobs and everything in-between. I'm drawn to problems that involve **connecting systems together**: payment infrastructure, third-party APIs, and data that has meaningful relationships (not just rows in a table).

I'm currently finishing my BSc in Computer Science, and actively looking to grow into backend and systems-level engineering alongside the frontend work I started with.

- 🌍 Based in Nigeria, open to remote collaboration and relocation
- 🎯 Currently deepening: cloud infrastructure, containerization, and backend testing practices
- 🤝 Always open to collaborating on full-stack or backend-leaning projects
